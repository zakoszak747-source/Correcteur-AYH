CORRECTEUR AYH - INSTALLATION

A. Obtenir la clé de l'IA
Option gratuite (Google Gemini) :
1. Va sur aistudio.google.com/app/apikey, connecte-toi avec un compte Google.
2. "Create API key" (créer une clé API), puis copie la clé.
Option payante (Claude) : console.anthropic.com, achat de crédits, puis API Keys.

B. Créer le service IA partagé (une seule fois)
1. Sur dash.cloudflare.com (compte gratuit) : Workers et Pages > Créer > Worker > Déployer.
2. Modifier le code : remplace tout par le contenu de worker.js > Déployer.
3. Paramètres > Variables et secrets : ajoute (type Secret)
   - GEMINI_API_KEY = ta clé Gemini  (ou ANTHROPIC_API_KEY si tu utilises Claude)
   - ACCESS_CODES = un ou plusieurs codes d'accès inventés par toi, séparés par des virgules
4. Déployer. Note l'adresse du Worker (https://NOM.TON-COMPTE.workers.dev).

C. Héberger l'application
Mets index.html, manifest.webmanifest, sw.js, icon-192.png et icon-512.png à la racine d'un dépôt GitHub (GitHub Pages) ou sur Netlify.

D. Installer et configurer
1. Ouvre l'adresse de l'application dans Chrome > menu > Installer l'application.
2. Menu > Réglages de l'IA > adresse du Worker + code d'accès > Enregistrer > Tester l'IA maintenant.
3. Autre appareil : "Copier le lien de configuration", envoie-le, l'enseignant l'ouvre et installe l'application.

Pour couper l'accès à quelqu'un : change ou retire son code dans ACCESS_CODES.
Attention : avec le quota gratuit de Gemini, ne pas envoyer de données sensibles (le contenu peut servir à améliorer les produits de Google).

Choisir le modèle Gemini (facultatif)
Sans réglage, le Worker utilise gemini-3.5-flash-lite (modèle économique, quota gratuit limité). Autres choix possibles : gemini-3.6-flash ou gemini-3.8-flash (plus précis, peut-être payants). Pour en changer, ajoute dans Cloudflare la variable GEMINI_MODEL (type Texte, onglet Production) avec le nom exact du modèle affiché dans Google AI Studio, puis Déployer.
Le modèle gemini-2.5-flash n'est plus proposé aux nouveaux comptes.
Si le modèle est payant et que ton compte est gratuit, l'IA renverra une erreur de quota : regarde dans AI Studio quel modèle est indiqué comme gratuit.

QUOTAS PAR CODE D'ACCES (pour vendre ou partager sans perte)
1. ACCESS_CODES accepte une limite d'appels IA par mois après deux-points :
   MonCodePerso,Prof-Marie-4821:300,Prof-Koffi-7733:150
   (MonCodePerso n'a aucune limite ; Marie a 300 appels IA par mois ; Koffi 150.)
   Un code ne doit contenir ni virgule ni espace ; évite les accents.
2. Crée un stockage KV : Cloudflare > Stockage et bases de données (Storage & Databases) > KV > Create namespace (nom : quotas).
3. Dans ton Worker : Settings > Bindings > Add > KV namespace > nom de variable QUOTA > choisis le namespace quotas > Deploy.
4. Un appel IA = une demande réussie (une copie corrigée, une épreuve lue, 6 pages analysées en lot...). Le compteur repart à zéro chaque mois.
5. Chaque enseignant voit son quota dans l'application : Menu > Réglages de l'IA > Voir mon quota du mois.
6. Toi, tu peux voir les compteurs de tous : Cloudflare > KV > quotas > entrées (clés u:CODE:AAAA-MM).
Quand le quota est atteint, l'application affiche : "Quota du mois atteint : demande une recharge à ton fournisseur". Pour recharger : augmente le nombre après le code dans ACCESS_CODES et Déployer.
Attention : l'offre gratuite de KV limite le nombre d'écritures par jour ; c'est suffisant pour quelques dizaines de copies par jour.

ABONNEMENTS (codes avec durée, quota, renouvellement, suspension)
Mise en place (une fois, après avoir créé le stockage KV QUOTA décrit plus haut) :
1. Cloudflare > ton Worker > Settings > Variables et secrets : ajoute ADMIN_CODE (type Secret) = ton code administrateur, long et secret, sans accent ni espace. Déployer.
2. Dans l'application : Menu > Réglages de l'IA > mets TON code administrateur comme "Code d'accès" > Enregistrer.
3. Même écran > "Gérer les abonnements (administrateur)".

Vendre un abonnement :
1. Le client te paie (Mobile Money, espèces...).
2. Dans "Gérer les abonnements" : saisis son nom, le nombre d'appels IA par mois et la durée en jours (30 = un mois), puis "Créer le code".
3. "Envoyer par WhatsApp" : le client reçoit son code et un lien qui configure l'application tout seul.
4. Renouvellement : "+30 jours" ou "+90 jours" sur sa fiche. Impayé : "Suspendre". Fin : "Supprimer".
Chaque client voit sa date de fin et son quota dans Menu > Mon abonnement. Quand l'abonnement est expiré, suspendu ou le quota atteint, l'application affiche un message clair et l'IA s'arrête (ses épreuves, photos et notes restent sur son téléphone).
Ton code administrateur utilise l'IA sans limite. Les codes de la variable ACCESS_CODES continuent de fonctionner (sans date de fin).
Le paiement n'est pas automatique : tu crées le code après avoir reçu l'argent.

EXPORTS WORD ET PDF
- Grille : mise en page identique à ta grille d'origine (titre, tableau Critères / Indicateurs / Consigne 1 / Pts / Consigne 2 / Pts, points en rouge), puis la situation, les consignes, les autres parties de l'épreuve et le corrigé type.
- Boutons : Exporter la grille (Word), Exporter la grille (PDF), Exporter le dossier complet (ZIP : Word + PDF).
- Résultats de la classe, fiches des élèves (toutes ou une seule) et rapport du test d'efficacité : Word et PDF.
- La sauvegarde complète (.zip) contient maintenant aussi les documents Word de chaque épreuve (dossier documents/).
- Le PDF utilise une bibliothèque chargée au premier export (connexion nécessaire une fois) ; elle reste ensuite en mémoire pour l'application installée.
