CORRECTEUR AYH - INSTALLATION

A. Créer le service IA partagé (une seule fois)
1. Sur console.anthropic.com : crée une clé API (API Keys), ajoute un petit crédit et fixe une limite de dépense.
2. Sur dash.cloudflare.com (compte gratuit) : Workers et Pages > Créer > Worker > nomme-le (ex. correcteur-ayh) > Déployer.
3. Modifier le code : remplace tout par le contenu du fichier worker.js > Déployer.
4. Paramètres > Variables et secrets : ajoute
   - ANTHROPIC_API_KEY = ta clé API (type Secret)
   - ACCESS_CODES = un ou plusieurs codes d'accès choisis par toi, séparés par des virgules (type Secret)
5. Note l'adresse du Worker (https://correcteur-ayh.TON-COMPTE.workers.dev).

B. Héberger l'application
Mets index.html, manifest.webmanifest, sw.js, icon-192.png et icon-512.png à la racine d'un dépôt GitHub (GitHub Pages) ou sur Netlify.

C. Installer et configurer
1. Ouvre l'adresse de l'application dans Chrome > menu > Installer l'application.
2. Accueil > Réglages de l'IA > colle l'adresse du Worker et ton code d'accès > Enregistrer.
3. Pour un autre appareil : dans les mêmes réglages, "Copier le lien de configuration", envoie-le à l'enseignant, il l'ouvre et installe l'application : l'IA est déjà configurée.

Pour couper l'accès à quelqu'un : change ou retire son code dans ACCESS_CODES.
